Docker üzerinde PostgreSQL 18 Çalıştırma
--------------------------------------------

Docker komutları
----------------------

docker images
docker ps (çalışan)
docker ps -a (çalışan çalışmayan hepsi)
docker build
docker run
docker exec -it (çalışan docker'a bağlanma)
docker rm (container silme)
docker rmi (image silme)


docker_test diye bir dizin oluştur. İçinde Dockerfile oluştur.

1 - Dockerfile yaz

FROM postgres:18-alpine

ENV POSTGRES_DB=testdb
ENV POSTGRES_USER=postgres
ENV POSTGRES_PASSWORD=postgres

EXPOSE 5432


2 - Dockerfile build et

docker build -t postgres18 .

3 - Docker image'ı çalıştır.

docker run -d --name postgres18 -p 5432:5432 -v postgres18_data:/var/lib/postgresql postgres18

4 - Docker'da çalışan postgresql'e bağlan

docker exec -it postgres18 psql -U postgres -d testdb


PGAdmin Kuruyoruz
------------------------------------------------

1 - Docker network oluştur

docker network create pg-network

2 - postgres18'i de bu network'e bağla.

docker network connect pg-network postgres18

3 - pgadmin diye bir altdizin oluşturup, o dizin içinde Dockerfile oluşturalım.

FROM dpage/pgadmin4:latest

ENV PGADMIN_DEFAULT_EMAIL=admin@admin.com
ENV PGADMIN_DEFAULT_PASSWORD=admin

EXPOSE 80

4 - Dockerfile build et.

docker build -t pgadmin .

5 - Docker pgadmin çalıştır

docker run -d --name pgadmin --network pg-network -p 5050:80 -v pgadmin_data:/var/lib/pgadmin pgadmin

6 - http://localhost:5050   adresinden bağlanın.

7 - pgadmin'i postgres'e bağlarken connection bölümünde hostname'e postgresql'in coniner adı yazılacak.
